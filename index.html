Reflection

ปัญหาและวิธีแก้:

คือการตกแต่งข้อมูลและจัดวางเลย์เอาต์ เพราะมีหัวข้อค่อนข้างเยอะทำให้อ่านยากและไม่เป็นระเบียบ แก้ไขโดยใช้ Flexbox ทำให้สามารถแยกหัวข้อออกได้เป็นระเบียบและอ่านง่าย

สิ่งที่ได้เรียนรู้:

ได้ลงมือทำหน้าเว็บเอง เข้าใจโครงสร้างของ HTML และ CSS มากขึ้น ฝึกออกแบบและตกแต่งหน้าเว็บ และได้ลองใช้คำสั่งใหม่ๆ

แนวทางพัฒนาต่อ:

ถ้าสามารถใช้ JavaScript ได้ผมก็อยากลองใช้เพื่อเพิ่มฟีเจอร์ใหม่ๆ ลองใช้คำสั่งอื่นๆของ HTML และ CSS เพื่อให้ตัวเว็บมีความหลากหลายของฟีเจอร์ และเพิ่มความสวยงาม
